# Карта экранов приложения

## 1. Рабочий стол

Главный экран после входа.

Для руководителя:

- активные объекты;
- проблемные объекты;
- договоры, которые скоро заканчиваются;
- просроченные задачи;
- допработы на согласовании;
- сверхбюджетные затраты без решения;
- заявки на материалы с проблемами;
- объекты на закрытии документов.

Для Артема:

- объекты в работе;
- задачи прорабов;
- допработы и отклонения;
- заявки, требующие решения;
- фотоотчеты за день;
- просрочки.

Для Анастасии:

- новые заявки на материалы;
- заявки на уточнении;
- доставки на сегодня;
- поставщики;
- заявки, ожидающие внесения в Сметтер;
- проблемные закупки.

Для прораба:

- мои объекты;
- мои задачи;
- создать заявку на материалы;
- добавить фотоотчет;
- отметить проблему или допработу.

## 2. Список объектов

Фильтры:

- статус;
- прораб;
- руководитель;
- сметчик;
- снабженец;
- сроки;
- наличие проблем;
- наличие сверхбюджета;
- незакрытые документы.

Колонки:

- объект;
- заказчик;
- статус;
- прораб;
- срок;
- открытые задачи;
- заявки;
- допработы;
- сумма сверхбюджета;
- ближайший риск.

## 3. Карточка объекта

Верхняя часть:

- название;
- статус;
- адрес;
- ссылка на навигатор;
- заказчик;
- ответственные;
- сроки;
- ссылки на Bitrix и Сметтер.

Вкладки:

- обзор;
- задачи;
- материалы;
- допработы и отклонения;
- документы;
- договоры;
- фото;
- согласования;
- история.

## 4. Вкладка "Обзор"

Показывает:

- текущий статус;
- ближайшие задачи;
- открытые заявки;
- активные допработы;
- сверхбюджет;
- документы, требующие внимания;
- последние фото;
- последние события.

## 5. Вкладка "Материалы"

Список заявок по объекту.

Фильтры:

- статус закупки;
- основание;
- договор/допник;
- поставщик;
- статус Сметтера;
- срок доставки.

Действия:

- создать заявку;
- согласовать;
- отправить в закупку;
- отметить доставку;
- отметить внесение в Сметтер;
- связать с актом.

## 6. Форма заявки на материалы

Обязательные поля:

- объект;
- срок поставки;
- основание;
- раздел сметы;
- материалы;
- количество;
- комментарий.

Если выбрано основание сверх основной сметы, система требует:

- причину;
- фото/обоснование;
- ответственное решение;
- связь с допработой или отклонением.

## 7. Вкладка "Допработы и отклонения"

Показывает:

- допработы;
- перерасходы;
- замены;
- скрытые работы;
- ошибки сметы;
- спорные позиции;
- затраты за счет компании.

Колонки:

- тип;
- описание;
- сумма;
- статус;
- решение;
- срок согласования;
- ответственный;
- связанный документ;
- статус Сметтера.

## 8. Карточка допработы / отклонения

Поля:

- тип;
- описание;
- причина;
- инициатор;
- фото/документы;
- раздел сметы;
- оценка;
- итоговая сумма;
- срок согласования;
- срок выполнения;
- ответственный;
- решение по деньгам;
- связанный допник;
- связанные заявки;
- связанный акт.

## 9. Раздел "Договоры"

Общий список договоров по компании.

Фильтры:

- объект;
- тип;
- контрагент;
- ответственный;
- дата окончания;
- статус;
- просроченные;
- скоро заканчиваются;
- без даты окончания.

Действия:

- добавить договор;
- добавить допсоглашение;
- продлить;
- закрыть;
- назначить ответственного;
- настроить напоминания.

## 10. Раздел "Документы"

Общий архив с фильтрами по объектам и типам документов.

Важно: документы должны иметь тип, статус, дату, версию и связь с объектом. Просто склад файлов без структуры не решит проблему.

## 11. Фотоотчеты

Форматы просмотра:

- лента по объекту;
- календарь;
- по этапам;
- по помещениям/зонам;
- только скрытые работы;
- только фото для заказчика.

## 12. Справочники

Поставщики:

- название;
- категория;
- адрес;
- навигатор;
- контакты;
- условия;
- комментарии.

Локации объектов:

- адрес;
- ссылка на навигатор;
- контакты на объекте;
- правила доступа.
