# Инфографика ролей и доступов

Дата: 2026-05-21

Этот файл фиксирует роль как должность. Детальная матрица по конкретным сотрудникам лежит отдельно: [Матрица доступов по сотрудникам](19-employee-access-matrix.md).

## Разделы Интерфейса

| Роль | Видит разделы | Не видит разделы |
| --- | --- | --- |
| Ген.директор | Рабочий стол, Объекты, Задачи, Работы, Материалы, Допработы, Локации, База знаний, Обратная связь, Журнал | Нет скрытых разделов |
| Фин.директор | Рабочий стол, Объекты, Задачи, Работы, Материалы, Допработы, Локации, База знаний, Обратная связь, Журнал | Нет скрытых разделов, но нет удаления |
| Рук. строительства | Рабочий стол, Объекты, Задачи, Работы, Материалы, Допработы, Локации, База знаний, Обратная связь, Журнал | Нет скрытых разделов |
| Менеджер | Рабочий стол, Объекты, База знаний | Задачи, Работы, Материалы, Допработы, Локации, Обратная связь, Журнал |
| Прораб | Рабочий стол, Задачи, Работы, Материалы, Допработы, Локации, База знаний | Объекты, Обратная связь, Журнал |
| Снабжение | Рабочий стол, Объекты, Материалы, Локации, База знаний | Задачи, Работы, Допработы, Обратная связь, Журнал |
| Сметчик | Рабочий стол, Объекты, Задачи, Работы, Материалы, Допработы, База знаний | Локации, Обратная связь, Журнал |
| Технадзор | Рабочий стол, Объекты, Задачи, Работы, Материалы, Локации, База знаний | Допработы, Обратная связь, Журнал |
| Бухгалтер | Рабочий стол, Объекты, Материалы, Допработы, Локации, База знаний, Журнал | Задачи, Работы, Обратная связь |

## Смысловые Ограничения

| Роль | Основное ограничение |
| --- | --- |
| Ген.директор | Полный доступ, включая окончательное удаление объектов |
| Фин.директор | Полный обзор и согласования, но без любых действий удаления |
| Рук. строительства | Полное управление строительным контуром, может удалять задачи и материалы базы знаний |
| Менеджер | Запускает объект, добавляет договоры/допники и передает объект в работу, не работает в задачах/материалах/работах/допработах |
| Прораб | Видит только то, что относится к закрепленным за ним объектам; финансовые суммы и договоры скрыты |
| Снабжение | Работает с заявками и поставками; финансовые документы, задачи и допработы скрыты |
| Сметчик | Видит сметный контур, работы, материалы и допработы; не видит локации и обратную связь |
| Технадзор | Контролирует задачи и выполнение, но не видит финансовые решения по допработам |
| Бухгалтер | Заготовка под будущий учет: финансовый просмотр без рабочих действий |

## Важно

Скрытие меню продублировано серверными проверками там, где это критично: обратная связь, допработы, финансовые данные и выгрузки. Это нужно, чтобы сотрудник не мог получить закрытую информацию прямым API-запросом, даже если кнопка на экране скрыта.
