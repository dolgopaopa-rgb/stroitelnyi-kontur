# Хранение доступов и секретов

Этот проект не хранит пароли, токены и ключи в GitHub. Все рабочие секреты должны оставаться только на сервере.

## Где лежат доступы

На сервере Selectel:

```bash
/opt/stroitelnyi-kontur/.env
/opt/stroitelnyi-kontur/secrets/app-access-current.txt
```

Файл `.env` используется приложением и Docker Compose. Файл `secrets/app-access-current.txt` нужен как серверная памятка с текущими логинами и паролями приложения.

Оба файла доступны только пользователю `root` и не должны копироваться в репозиторий.

## Как посмотреть доступы без публикации в чат

Подключиться к серверу по SSH и открыть файл там:

```bash
ssh -i ~/.ssh/stroitelnyi_kontur_selectel_rsa root@79.143.30.43
cd /opt/stroitelnyi-kontur
cat secrets/app-access-current.txt
```

После просмотра не вставлять содержимое в Codex, MAX, Telegram или GitHub.

## Что нельзя делать

- Нельзя писать пароли и токены в чат.
- Нельзя коммитить `.env`, файлы из `secrets/`, SSH-ключи и OAuth-токены.
- Нельзя отправлять общий список паролей коллегам в общий чат.

## Что делать при утечке

Если пароль, токен или client secret попал в чат, его нужно считать раскрытым и заменить. Для приложения это делается заменой значений `APP_BASIC_AUTH_PASSWORD` и `APP_ACCESS_ACCOUNTS` в серверном `.env` с последующим перезапуском контейнера.

## Что уже сделано

- Рабочие доступы приложения перенесены в серверный `.env`.
- Создан серверный файл `secrets/app-access-current.txt`.
- Старые пароли приложения заменены на новые.
- `.env` и файл текущих доступов закрыты правами `600`.
- Папка `secrets` закрыта правами `700`.
