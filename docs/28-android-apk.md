# Android APK

## Что сделано

Добавлен первый APK-вариант для Android. Это нативная WebView-обертка вокруг боевого сайта `https://kontur.derevgroup.ru`.

Такой подход выбран как быстрый и надежный первый шаг:

- сотрудники устанавливают обычный APK;
- не появляется отдельная база данных;
- все документы, роли, уведомления, заявки и история остаются в текущем Контуре;
- изменения на сервере сразу видны и в APK;
- не нужно заново писать всю мобильную логику.

## Что умеет первая сборка

- Открывает Контур внутри Android-приложения.
- Сохраняет обычную сессию входа через сайт.
- Поддерживает загрузку файлов с телефона через системный выбор файла.
- Поддерживает скачивание файлов в папку Downloads.
- Открывает внешние ссылки, включая Яндекс.Карты, во внешнем приложении.
- Показывает тонкую полоску загрузки сверху.
- Кнопка Android `Назад` сначала возвращает на предыдущую страницу Контура, а потом закрывает приложение.

## Как собрать APK

Из корня репозитория:

```powershell
.\tools\build-android-apk.ps1
```

Скрипт сам скачивает локальные JDK, Gradle и Android SDK в папку `.android-build-tools`.

## Где готовый APK

```text
dist/android/stroitelnyi-kontur-debug.apk
```

## Как установить на телефон

1. Передать APK на Android-телефон.
2. Открыть файл на телефоне.
3. Если Android попросит разрешить установку из этого источника, разрешить.
4. Нажать `Установить`.
5. После установки открыть приложение `Строительный контур`.
6. Войти своим логином и паролем.

## Важное ограничение

Сейчас это debug-сборка для внутреннего тестирования. Для постоянного распространения нужно сделать release-сборку с отдельным ключом подписи и хранить ключ вне репозитория.
