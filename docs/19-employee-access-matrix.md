# Матрица доступов по сотрудникам

Дата: 2026-05-21

Матрица показывает, что каждый сотрудник видит в левом меню, чего не видит, и какие ключевые действия ему разрешены. Это текущая рабочая версия прав.

## Легенда

| Обозначение | Значение |
| --- | --- |
| Видит | Раздел есть в меню |
| Не видит | Раздел скрыт из меню |
| Частично | Раздел виден, но данные внутри ограничены |
| Да | Действие разрешено |
| Нет | Действие запрещено |

## Текущая Логика По Сотрудникам

### Ген.директор

Видит и управляет всем. Единственный, кто может удалить объект навсегда из архива.

### Фин.директор

Видит все разделы и финансовую информацию, может согласовывать и принимать управленческие решения. Не видит кнопки удаления и не может удалять через сервер.

### Бухгалтер

Пока заготовка. Видит финансовый контур и документы, но не участвует в задачах, работах и управлении объектами.

### Алексей, менеджер

В меню оставлены только: Рабочий стол, Объекты, База знаний. Он заводит объект, прикладывает первичные документы, добавляет договоры/допники, передает объект в работу и видит только нужный ему контур.

### Прорабы Андрей и Сергей

В меню оставлены только: Рабочий стол, Задачи, Работы, Материалы, Допработы, Локации, База знаний. Отдельная вкладка Объекты скрыта. Внутри рабочих разделов каждый прораб видит только данные по закрепленным за ним объектам. Финансовые суммы, договоры и управленческие решения по деньгам скрыты.

### Анастасия, снабжение

Видит материалы, заявки, объекты для понимания адреса и контекста, локации и базу знаний. Не видит задачи, работы, допработы, журнал и обратную связь.

### Ксения и Илья, сметчики

Видят сметный контур: объекты, задачи, работы, материалы, допработы и базу знаний. Локации, журнал и обратная связь скрыты.

### Технадзор

Видит контрольный строительный контур: объекты, задачи, работы, материалы, локации и базу знаний. Допработы и финансовые решения скрыты.

## Что Нужно Уточнить Позже

1. Должен ли бухгалтер видеть будущие счета, оплаты и поставщиков.
2. Нужно ли снабжению видеть часть допработ, если они возникли из материалов.
3. Должен ли технадзор видеть допработы без сумм, если они влияют на качество или объем работ.
4. Нужно ли прорабам показывать компактную карточку объекта внутри рабочих разделов, раз отдельная вкладка Объекты скрыта.
