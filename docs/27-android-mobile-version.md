# Android-версия Строительного контура

## Что сделано

Первый мобильный вариант сделан как PWA-приложение для Android. Это означает:

- Контур ставится на телефон из Chrome без Play Market.
- На рабочем столе телефона появляется отдельная иконка.
- Приложение открывается в отдельном окне без адресной строки браузера.
- Вход сохраняется через обычную сессию Контура.
- Все данные остаются на том же сервере `kontur.derevgroup.ru`.
- Не появляется вторая база и отдельная мобильная логика.

## Как установить на Android

1. Открыть на телефоне Chrome.
2. Перейти на `https://kontur.derevgroup.ru`.
3. Если появилась кнопка `Установить на Android` или `Установить`, нажать ее.
4. Если кнопка не появилась, открыть меню Chrome `⋮`.
5. Выбрать `Установить приложение` или `Добавить на главный экран`.
6. Подтвердить установку.
7. Запускать Контур с иконки на рабочем столе телефона.

## Что изменено технически

- Manifest и service worker стали доступны до авторизации.
- Статические файлы `/static/*` стали доступны до авторизации.
- Данные приложения и API по-прежнему закрыты логином.
- На странице входа добавлена кнопка установки для Android.
- Внутри приложения добавлена кнопка установки в верхнюю панель.
- Manifest дополнен Android shortcuts: рабочий стол, объекты, задачи, материалы.
- QA-агент получил сценарий `Android PWA install scenario`.

## Следующий этап

Если PWA-вариант устроит по поведению, можно оставить его как рабочую Android-версию.

Если понадобится APK или размещение в RuStore/Google Play, следующий шаг - сделать Trusted Web Activity-обертку. Она будет открывать тот же Контур, но распространяться как обычный установочный пакет.
