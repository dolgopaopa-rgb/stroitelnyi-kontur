# Android APK

Первый APK для Android сделан как нативная WebView-обертка вокруг боевого Контура:

- адрес приложения: `https://kontur.derevgroup.ru`;
- база, файлы, роли и уведомления остаются на сервере;
- APK нужен только для удобного входа с телефона;
- внешние ссылки, например Яндекс.Карты, открываются во внешнем приложении;
- загрузка файлов с телефона поддерживается через системный выбор файла.

## Сборка

Основная команда из корня репозитория:

```powershell
.\tools\build-android-apk.ps1
```

Скрипт скачивает локальные JDK, Gradle и Android SDK, если их нет, затем собирает debug APK.

Готовый файл появляется здесь:

```text
dist\android\stroitelnyi-kontur-debug.apk
```

## Установка

1. Передайте APK на Android-телефон.
2. Откройте файл.
3. Разрешите установку из этого источника, если Android спросит.
4. Нажмите `Установить`.
5. Откройте `Строительный контур` и войдите в свою учетную запись.

Это тестовая debug-сборка для ручной установки. Для постоянного распространения следующим шагом нужно сделать release-сборку с отдельным ключом подписи.
