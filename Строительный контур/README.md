# Строительный контур

Эта папка нужна как рабочая точка входа по программе, чтобы можно было открыть репозиторий с другого компьютера и быстро понять:

- что это за программа;
- где смотреть текущий статус;
- куда записывать дальнейшие изменения;
- как продолжать работу без потери контекста.

## Главное правило

Каждый дальнейший заметный шаг по программе нужно фиксировать в файле:

- `Журнал дальнейших шагов.md`

Запись должна быть понятной не программисту: что попросили, что изменено в программе, что нужно проверить коллегам, есть ли открытые вопросы.

## Где смотреть подробности

- `docs/16-project-worklog.md` - подробный технический журнал всех изменений.
- `docs/26-new-chat-handoff.md` - передача проекта в новый чат: карта файлов, процессы, проверки и правила безопасности.
- `docs/14-working-from-another-computer.md` - как продолжить работу с другого компьютера.
- `docs/19-employee-access-matrix.md` - матрица ролей и доступов.
- `docs/17-quality-agent.md` - как работает проверяющий агент.
- `app/` - рабочая программа.

## Текущий рабочий контур

- Постоянный сайт: `https://kontur.derevgroup.ru`
- Основная ветка GitHub: `main`
- В MAX отправлять только пользовательские сообщения: что изменилось в программе и что нужно сделать коллегам. Не отправлять туда коммиты, серверные детали, названия файлов, результаты технических проверок и другую программистскую информацию.
