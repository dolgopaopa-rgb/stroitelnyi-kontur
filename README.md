## Прототип

[Открыть кликабельный прототип](prototype/index.html)

Что уже можно проверить:

- рабочий стол руководителя;
- переключение рабочих сценариев по ролям;
- список объектов;
- создание объекта после передачи из Bitrix;
- карточку объекта с вкладками и контрольным списком;
- общий раздел задач и создание задач;
- заявки на материалы;
- предупреждение при заявке сверх основной сметы;
- допработы и отклонения;
- отдельный раздел согласований;
- журнал событий вместо поиска решений в чатах;
- договоры со сроками окончания;
- создание договора с напоминаниями;
- общий контроль сроков по договорам, задачам, заявкам, согласованиям и документам;
- добавление документов с типом, версией, сроком и ответственным;
- очередь Сметтера для контроля двойной работы;
- раздел локаций: адреса объектов и поставщиков;
- фотоотчеты с привязкой к объекту и отметкой для заказчика;
- архив документов.

## Рабочее приложение

[Папка первой программной версии](app/README.md)

Это уже не статический прототип: приложение запускает локальный сервер, создает SQLite-базу и работает через API.

Что уже реализовано:

- база данных;
- API;
- рабочий стол;
- объекты;
- задачи;
- заявки на материалы;
- выбор материала в заявке из списка материалов сметы;
- импорт сметных материалов из CSV внутри раздела Материалы;
- документы;
- журнал событий;
- формы создания новых записей.

## Граница продукта

Bitrix остается для продаж до договора. Новая система начинается после передачи объекта в строительство и отвечает за объекты, задачи, документы, заявки, фото, допработы, договоры, сроки и связь со Сметтером.
