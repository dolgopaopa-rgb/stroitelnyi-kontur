## Рабочее приложение

[Папка первой программной версии](app/README.md)

Это уже не статический прототип: приложение запускает локальный сервер, создает SQLite-базу и работает через API.

### Облачный тест

Код подготовлен для запуска на Render из GitHub:

[Deploy to Render](https://render.com/deploy?repo=https://github.com/dolgopaopa-rgb/stroitelnyi-kontur)

Важно: бесплатный облачный запуск подходит для проверки коллегами, но не для настоящих рабочих данных. У бесплатного сервера файловая база SQLite может сбрасываться при перезапуске или redeploy. Для постоянной работы нужно будет подключить нормальное хранилище: PostgreSQL или платный диск.

### Постоянный сервер

Для собственного VPS подготовлены Docker-файлы, Caddy для HTTPS, постоянный volume под базу, базовая защита логином/паролем, скрипты запуска, обновления, бэкапа и восстановления. Инструкция: [Постоянный сервер](docs/12-deployment.md).

Что уже реализовано:

- база данных;
- API;
- рабочий стол;
- объекты;
- задачи;
- заявки на материалы;
- выбор материала в заявке из списка материалов сметы;
- импорт сметных материалов из CSV внутри раздела Материалы;
- документы;
- журнал событий;
- формы создания новых записей.

## Граница продукта

Bitrix остается для продаж до договора. Новая система начинается после передачи объекта в строительство и отвечает за объекты, задачи, документы, заявки, фото, допработы, договоры, сроки и связь со Сметтером.
