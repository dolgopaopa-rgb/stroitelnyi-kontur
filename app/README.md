# Рабочее приложение MVP

Это первая программная версия строительного контура.

Она отличается от `prototype/` тем, что данные хранятся в базе SQLite, а интерфейс работает через API.

## Как запустить

Самый простой вариант:

```text
start-server.bat
```

Или вручную из папки `app`:

```powershell
& 'C:\Users\seven\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' server.py
```

После запуска открыть:

```text
http://127.0.0.1:8765
```

## Как запустить на постоянном сервере

Для VPS подготовлен запуск через Docker Compose из корня репозитория:

```bash
cp .env.example .env
bash deploy/first-run.sh
```

В `.env` нужно указать домен и пароль. Подробная инструкция лежит в `docs/12-deployment.md`.

## Что уже есть

- база SQLite;
- тестовые пользователи;
- объекты;
- задачи;
- заявки на материалы;
- выбор материала в заявке из списка материалов сметы;
- документы;
- журнал событий;
- создание новых объектов, задач, заявок, документов и событий.

## Материалы из сметы

В базе появилась таблица `estimate_materials`.

Сейчас можно загрузить материалы из CSV-файла, сохраненного из Excel. Импорт находится внутри раздела **Материалы**, рядом с заявками.

Пример файла:

```text
sample-estimate-materials.csv
```

Ожидаемые колонки:

- Раздел
- Наименование
- Ед
- Количество
- Цена
- Сумма

Следующий шаг: добавить прямой импорт `.xlsx`, когда будет понятен реальный формат выгрузки из Сметтера.
## Текущая сборка для проверки

В рабочем приложении сейчас можно проверить полный основной контур:

- создание объекта после передачи из Bitrix;
- привязку материалов к объекту и выбор материала из загруженного списка сметы;
- импорт материалов сметы из CSV внутри раздела **Материалы**;
- создание задач, документов и событий по объектам;
- создание допработ и отклонений с суммой, сроком и решением по деньгам;
- создание договоров и допсоглашений со сроком действия;
- общий контроль сроков по договорам, задачам и заявкам на материалы.

## Импорт из Сметтера

Раздел **Материалы** теперь принимает реальную выгрузку Сметтера в формате `.xlsx` вида “Бюджет закупок”.

При импорте приложение берет строки, где в колонке **тип** указано `мат`, и переносит:

- раздел/этап сметы;
- позицию материала;
- единицу измерения;
- бюджетное количество;
- цену;
- бюджетную сумму.

Строки “Итого”, подписи и шапка документа не импортируются.
